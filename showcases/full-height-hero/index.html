What you're testing

The hero above is sized with the selected unit. As the mobile address bar shows/hides, the visible viewport height changes. A dynamic unit (dvh) resizes the hero live — which shifts everything below and makes your scroll jump. A static unit (svh/lvh) or a frozen measurement holds steady.

Try this on your phone

1) Pick 100dvh, scroll up and down — note the hero height number changing in the readout. 2) Switch to 100svh and do the same — the hero height stays put. That stability is the whole point.

Recommendation

Default to min-height: 100svh with a 100vh fallback for full-height sections. Reserve dvh for small UI (e.g. a sticky bottom bar), not large heroes.
